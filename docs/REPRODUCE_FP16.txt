2. RUN THE CONVERTER WITH YOUR COMFYUI PYTHON

From the repository root containing tools, use the same Python environment as ComfyUI, with NumPy installed:

python tools/convert_fp16.py --comfyui-root "YOUR_COMFYUI_FOLDER"

YOUR_COMFYUI_FOLDER is the folder containing models and custom_nodes, not the portable distribution's parent folder. With Windows portable ComfyUI, use your python_embeded/python.exe instead of an unrelated system Python.

The tool reads and hashes the originals in bounded CPU chunks, checks finite values and FP16 range, preserves keys/shapes, and validates the derived files before publishing them. It preserves the originals and refuses to overwrite an existing destination or .incomplete staging file. Publication requires a filesystem supporting hardlinks; unsupported filesystems fail closed without a replacement-capable rename fallback. It does not load a GPU model, install nodes, queue inference, or contact a service. If a valid converted copy already exists, use it instead of running the conversion again.
